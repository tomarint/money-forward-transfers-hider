# 🚀 Money Forward Transfers Hider

[➡️ 日本語版 (Japanese version)](README.md)

**Money Forward Transfers Hider** is a browser extension that hides transfers and transactions manually excluded from calculations on the Money Forward ME website.

## Installation

You can install it from your browser's extension store:

- <a href="https://chromewebstore.google.com/detail/money-forward-transfers-h/oofjhejmomjgdhfnplhebhbccapljaie" target="_blank">Chrome / Brave</a>
- <a href="https://microsoftedge.microsoft.com/addons/detail/money-forward-transfers-h/noildcjonpiommfamekbmbfgojdokpij" target="_blank">Edge</a>
- <a href="https://addons.mozilla.org/en-US/firefox/addon/money-forward-transfers-hider/" target="_blank">Firefox</a>

## How to use

1. Pin the extension icon to your browser's toolbar.
2. Open the Money Forward ME website.
3. Use the extension's switch to show or hide transfers and excluded transactions.
4. Check that transfers and excluded transactions are hidden.

If you have many transfers or excluded transactions in Money Forward ME, this makes it easier to find the information you need.
